# 📱 Mobile Installation Guide - Journify Đà Lạt

## 🚀 How to Install Journify on Your Mobile Device

Journify Đà Lạt is now available as a Progressive Web App (PWA) that can be installed on your mobile device just like a native app!

---

## 📋 Installation Steps

### **Step 1: Access the App**
Open your mobile browser and go to (only avaiable if my computer is on):
**🌐 https://censerless-untenably-mila.ngrok-free.dev**
Or download ngrok and run the local server to access it by the following command:
```ngrok http 8000
```



### **Step 2: Wait for Install Prompt**
- Browse the site for a moment
- Interact with the content (scroll, click buttons)
- An install prompt should appear automatically

### **Step 3: Install the App**

#### **On Android (Chrome/Samsung Internet):**
1. Tap the **"Add to Home Screen"** banner when it appears
2. Or tap the **⋮ menu** → **"Add to Home Screen"**
3. Tap **"Add"** or **"Install"**
4. The app icon will appear on your home screen

#### **On iOS (Safari):**
1. Tap the **Share button** (⬆️)
2. Scroll down and tap **"Add to Home Screen"**
3. Tap **"Add"** in the top right
4. The app icon will appear on your home screen

## 🔧 Troubleshooting Installation Issues

### **If "Add to Home Screen" only creates a shortcut:**
1. **Clear browser cache:**
   - Chrome: Settings → Privacy → Clear browsing data → Cached images and files
2. **Hard refresh:** Hold refresh button or use incognito mode
3. **Try multiple visits:** Some browsers require repeated visits
4. **Check browser console:** Look for PWA-related error messages

### **If no install prompt appears:**
- **Interact with the site** more (click buttons, scroll)
- **Wait a few minutes** between visits
- **Use Chrome** (best PWA support)
- **Ensure HTTPS** connection (ngrok provides this)
